Bekerja di worktree dan branch yang sudah ada; branch, push, dan PR lain bukan urusan sub sesi. Bila brief menandai "Sesi dipakai ulang: ya", konteks lama sudah dibersihkan: jalankan `git merge main` dulu, lalu pakai brief dan `git log --oneline main..HEAD`. Nama branch bisa warisan item lain; biarkan.

Semua itu tidak ada di repo ini dan tidak berlaku. Perintah verifikasi yang berlaku ada di butir "Verifikasi sebelum melapor" file ini; evidence dicatat di `verify.md` spec sesuai [acceptance evidence](../../testing/strategy.md#acceptance-evidence), bukan lewat xtask; format blok scope mengikuti `docs/scope/001-stack-and-workspace.md`.

Build atau run di macOS bukan bukti Linux dan bukan bukti CI. Langkah yang gagal atau flaky bukan langkah manual: laporkan `failed` dengan perintah dan outputnya.
