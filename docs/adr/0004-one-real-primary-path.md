# ADR 0004. One real primary path

The canonical decision and lifecycle status are in [spec 0004](../specs/0004-one-real-primary-path/index.md). Its [rationale](../specs/0004-one-real-primary-path/rationale.md) records alternatives, tradeoffs, and the decisions taken.

The decision is to build the first real client path as one narrow, fully specified thread: a `psql` client over TLS, authenticated with SCRAM against a verifier that POOL holds, mapped by the identity map to its own backend login, and connected to one new backend on the node that the journal, the configuration and a fresh probe all name as the writer. The wire code lives in two new crates, `pool-protocol` and `pool-core`. The journal file, the bootstrap command and the probe of spec 0003 are built here, and sessions read the writer from a topology snapshot that they check twice before any SQL is sent. The session accepts simple queries only, closes its backend when it ends, never sends anything again after a loss, and refuses with a fixed table of SQLSTATEs. The slice adopts the first runtime, TLS and SQLite dependencies, and with them the first native code. This ADR is an index entry, not a second decision record.
